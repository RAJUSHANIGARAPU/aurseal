# Wiki Search Flows

Three test scenarios covering the happy path, a boundary condition, and a
negative case for Wikipedia full-text search. Generated by `web_discovery`
after crawling the Wikipedia search surface.

---

## Scenario happy path search returns results

### Preconditions
- Browser is on the Wikipedia main page
- Cookie consent has been accepted
- Search input is visible

### Steps
1. Click the search input field
2. Type the search term `Playwright testing framework`
3. Press Enter to submit the search
4. Wait for page load state `networkidle`

### Expected
- Page URL contains `/wiki/` or `/w/index.php?search=`
- The page `<h1>` heading is visible
- At least one result item or article body paragraph is present
- No "no results" or error banner is displayed

### Tags
`smoke` `regression` `happy_path`

---

## Scenario boundary empty search term

### Preconditions
- Browser is on the Wikipedia main page
- Cookie consent has been accepted
- Search input is visible and empty

### Steps
1. Click the search input field
2. Leave the field empty (do not type anything)
3. Press Enter to submit the empty search
4. Wait for page load state `domcontentloaded`

### Expected
- The browser stays on the Wikipedia search or main page (no 5xx error)
- Either the search input is focused again, or a hint / autocomplete dropdown
  appears, or the page reloads without changing the URL path
- No unhandled JavaScript error is thrown (check `page.on("pageerror")`)

### Tags
`regression` `boundary`

---

## Scenario negative very long search string

### Preconditions
- Browser is on the Wikipedia main page
- Cookie consent has been accepted
- Search input is visible

### Steps
1. Click the search input field
2. Type a 500-character string: the letter `a` repeated 500 times
   (`"a" * 500`)
3. Press Enter to submit the search
4. Wait for page load state `networkidle`

### Expected
- The server responds with a valid HTTP 200 or redirect (no 4xx / 5xx)
- The page renders without a crash or blank body
- A "no results found" message OR a graceful empty-results page is shown
- The search input value on the result page is not truncated to fewer than
  200 characters (Wikipedia accepts long queries without silent truncation)

### Tags
`regression` `negative` `boundary`
