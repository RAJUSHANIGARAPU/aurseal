# What aurseal is

`aurseal` is a command-line tool and Python package (3.11+) for people who write test
automation and have to show it to someone: a take-home assignment, a proof of concept, a
new suite for a team.

It does four things:

1. **Scaffold.** `aurseal new-assignment` renders a project from a template: source
   layout, page objects or an API client, offline tests that pass on the first run, a
   test plan, lint and type-check configuration, a Makefile, a Dockerfile and a CI
   workflow. See [Templates](templates.md).
2. **Gate.** Every generated project passes through the [leak gate](leak-gate.md) before
   it is written to disk, so a private name or a personal email address never lands in
   the output. `aurseal assignment check` runs the same gate over a project you have
   edited since.
3. **Import.** [Importers](importers.md) read JUnit XML, Playwright JSON and the
   upload the pytest plugin writes into one result model (`aurseal.model.v1`), with a
   stable identity per test so re-imports do not create duplicates.
4. **Report.** `aurseal report` renders a self-contained HTML summary of one or more
   result files, with no JavaScript framework and no server.

## What it is not

- Not a test runner. Generated projects use pytest; the kit only creates and checks them.
- Not a hosted service. Everything here runs locally or in your own CI.
- Not a load-testing or device lab. The `perf-*` and `mobile` types scaffold the tests;
  the target, the load generator's capacity and the devices are yours.
