## Known Gaps

### Not yet automated

1. **Real screenshot comparison** — visual_regression.plugin.py creates placeholder baselines.
   Gap: needs actual Playwright page.screenshot() calls with pixel diff (pixelmatch/PIL).

2. **Semantic behavioral diffing** — behavioral_equivalence.plugin.py detects function set changes
   but does not execute functions and compare outputs. Gap: needs a sandbox execution environment.

3. **Axe-core actual execution** — accessibility_a11y.plugin.py generates test scripts but does not
   run them. Gap: requires axe-playwright dependency + Playwright session.

4. **mutmut integration** — mutation_testing.plugin.py requires mutmut to be installed separately.
   Gap: add mutmut to requirements.txt and configure CI.

5. **k6 execution** — load_performance.plugin.py generates scripts but only runs if k6 is in PATH.
   Gap: Docker-based k6 execution would make this portable.

6. **PROD_EVENT_LOG_PATH** — temporal_regression.plugin.py skips gracefully when not set.
   Gap: define a log format and configure the path in CI.

7. **CRITICAL tier plugins** — no plugin currently registers as CRITICAL priority.
   Gap: api-contract or security-scan should be promoted to CRITICAL for strict gates.

8. **Cross-plugin correlation** — findings from different plugins are not correlated.
   Gap: evolution_agent.py could analyze patterns across multiple plugin outputs.

## Recommendations

1. Promote `security-scan` to CRITICAL for deploy trigger
2. Add `axe-playwright` to requirements.txt to unlock accessibility execution
3. Set `PLUGIN_BUDGET_USD=2.0` in CI to control costs
4. Schedule `evolution_agent` weekly to track framework improvements
